Quand on tape une adresse qui n'existe pas, le site affiche maintenant une vraie page « **404 — Cette page a disparu** », avec un petit clin d'œil de paléontologue. Avant, on retombait sur l'accueil sans comprendre ce qui s'était passé.

- Deux boutons pour repartir : **Retour à l'accueil** et **Parcourir le codex**.
- Les moteurs de recherche savent désormais que l'adresse n'existe pas.
