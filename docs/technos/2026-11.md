## npm audit

- **Avant** : 15 vulnérabilités (2 low, 1 moderate, 11 high, 1 critical) — astro,
  vite, launch-editor, svgo, zod, devalue, postcss, nanoid, js-yaml, smol-toml,
  browserslist, source-map-js, sharp, esbuild, @astrojs/react…
- **Après** : 4 vulnérabilités (1 low, 1 moderate, 1 high, 1 critical), toutes
  rattachées à astro 6 : la correction proposée par npm est **astro 7** (majeure).
  - `astro <=7.4.6` (critical) — avis XSS au rendu de props/slots/transitions, RCE via
    l'optimisation d'images AVIF, SSRF de la page d'erreur prérendue, avis
    `@astrojs/node`. **Exposition chez nous : faible.** Sortie statique sans adaptateur,
    données figées au build (curées, pas saisies par un visiteur), aucun
    `astro:assets` / `<Image>` (donc pas d'optimisation AVIF par sharp), pas de
    `transition:*` ni `ClientRouter`.
  - `sharp <=0.35.5-rc.1` (high, libvips/libheif/librsvg) — tiré par astro, non utilisé au
    build (aucune image optimisée, `dist/_astro` ne contient ni webp ni avif).
  - `esbuild 0.27.3 – 0.28.0` (low) — lecture de fichiers par le serveur de dev **sous Windows** ;
    nous développons sous WSL Linux.
  - `@astrojs/mdx <=6.0.3` (moderate) — hérité d'astro.

## Régressions

- **Aucune régression de rendu.** Texte visible identique sur les 1533 pages de
  `dist` avant/après (scripts, styles et balises retirés) ; seuls changent les
  hachages `_astro/*` et les identifiants SVG aléatoires. Build vert (≈ 8 s),
  même taille (186 Mo), aucun avertissement.
- **Trouvé en route (préexistant, corrigé)** : avec `playwright-core` 1.63.0, qui attend
  Chromium révision 1243 (non installée), les 99 tests e2e de `npm run test:scripts`
  passaient en **skip** sans échouer. Symptôme : « 95 pass, 99 skipped ». Détection :
  lecture du motif de skip. Correction : épingler `playwright-core` 1.65.1, dont le
  Chromium (1255) est installé. Résultat : 194 pass, 0 skip.
